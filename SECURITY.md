# Security

Podium asks for the Accessibility and Screen Recording permissions, so a flaw in it matters.

## Report a vulnerability

Do not open a public issue. Use [private vulnerability reporting](https://github.com/reiald/podium/security/advisories/new) on this repository, or open the Security tab and choose Report a vulnerability. Include the macOS version, the steps to reproduce, and what an attacker could do.

I will reply within a week. Fixes are released as a new version, and the report is made public after the fix ships.

## Supported versions

Only the latest release gets fixes.
